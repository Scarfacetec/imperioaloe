# Imperio Aloe

Site estático responsivo da Imperio Aloe.

## Publicação no Cloudflare Pages

O projeto não possui etapa de compilação. No Cloudflare Pages, use:

- Framework preset: `None`
- Production branch: `main`
- Build command: `exit 0`
- Build output directory: `.`
- Root directory: deixe em branco
- Environment variables: nenhuma

O arquivo `_headers` é lido pelo Cloudflare Pages e adiciona cabeçalhos de segurança às páginas estáticas.

## Desenvolvimento local

Abra `index.html` em um navegador ou use um servidor estático local. Não há dependências para instalar.
